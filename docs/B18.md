# B18: Scheduled escalation

`run_escalation(now=None, notify=None)` records a run and processes eligible
past-due complaints in individual transactions. The `run_escalation` management
command runs the scheduled pass. The notification hook defaults to a no-op;
Head notification delivery belongs to F4.

When `run_escalation()` is called inside an outer transaction, notification
callbacks run after the outer commit, after the run has been finalized. A
notification failure then cannot be reflected in the run's error text. The
management command runs without an outer transaction.
