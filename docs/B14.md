# B14: Intake routing and priority

A trusted intake operation calls `route_and_prioritize` inside `execute_intake`:

```python
outcome = route_and_prioritize(
    complaint_id=ctx.complaint_id, category=category, location_code=location_code,
    indicated_priority=indicated_priority, submitted_at=ctx.submitted_at,
)
complaint = Complaint(..., **outcome.as_complaint_fields())
```

`as_complaint_fields()` supplies department, unrouted, routing_rule_key, priority,
due_at and ASSIGNED status for the Complaint. The Complaint copies these values in
the same transaction in which the append-only RoutingDecision is recorded. An SLA
or routing failure rolls back the whole intake.
