# E03: Deployment

## Database

SQLite is the default (`DJANGO_DB_ENGINE=sqlite`). `DJANGO_DB_PATH` optionally
sets its database file; the test database remains a separate file and SQLite
uses IMMEDIATE transactions with a 20-second timeout.

For PostgreSQL, required by SRS NFR-QUAL-05, set
`DJANGO_DB_ENGINE=postgresql`, `DJANGO_DB_NAME`, `DJANGO_DB_USER`,
`DJANGO_DB_PASSWORD`, and `DJANGO_DB_HOST`. `DJANGO_DB_PORT` defaults to 5432.
The password must be provided and must not be committed. Install the pinned
Psycopg binary dependency from `requirements.txt`.

The reported PostgreSQL 17 run passes all 825 tests after the cross-backend
exception adjustment, as does the SQLite suite. SQLite reports length
constraint rejections as `IntegrityError`; PostgreSQL can report `DataError`
when its varchar length limit rejects the same value first.

Complaint-ID allocation and intake rely on SQLite IMMEDIATE serialization and
must be verified on PostgreSQL, including the locking and concurrency paths in
`complaints/identifiers.py`, `complaints/intake.py`, and `routing/services.py`.
